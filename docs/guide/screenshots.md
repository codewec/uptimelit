# Screenshot gallery

The current monitor workspace uses a compact navbar, highlighted status badges and cards for HTTP and TCP services. The logo returns to monitors; the plus icon creates a monitor and the bell opens notification channels.

## Mocha dark theme

![UptimeLit monitor workspace in the Mocha dark theme](../../.github/images/screenshot-dark.png)

## Crema light theme

![UptimeLit monitor workspace in the Crema light theme](../../.github/images/screenshot-light.png)

Both views show **All**, **Up**, **Down** and **Paused** filters, recent check bars, 24-hour uptime, response times and HTTP status codes. Paused monitors remain visible in **All** and use muted history bars.

See [monitoring and themes](usage.md) for the controls and theme options, and [getting started](getting-started.md) to create your own workspace.
